How to use Celestial Parallels

Start from Earth

Start on Earth to pick testbeds or search any location via the top search bar. Then choose Mars match or Moon match to find similar environments.

Start from Mars or the Moon

Switch to Mars or Moon, select a landing zone, and find the closest field site on Earth.

About Celestial Parallels

An interactive tool for finding geological analog sites between Earth, Mars and the Moon, built on CesiumJS and multi-source planetary datasets.
